# GymBro

Osobní tracker cvičení (PWA). Data se ukládají jen v telefonu (localStorage), záloha je soubor JSON.

## Nasazení na GitHub Pages (zdarma, veřejný repozitář)
1. Repozitář → Settings → Pages → Source: "Deploy from a branch", Branch: main, složka / (root) → Save.
2. Za minutu je aplikace na `https://<uživatel>.github.io/<repozitář>/`.
3. V iPhonu otevři adresu v Safari → Sdílet → Přidat na plochu. Cviky zadávej až v aplikaci z plochy.

## Nová verze
Nahraj změněné soubory do repozitáře (stejné názvy). Nová verze se načte při dalším otevření s internetem, data zůstanou.
Adresa se nesmí měnit, data jsou vázaná na adresu. Před větší změnou udělej zálohu.
